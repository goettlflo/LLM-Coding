== Risiken und technische Schulden

[cols="1,3,1"]
|===
|ID |Risiko/Schuld |Bezug

|R-01 |Keine echte Authentifizierung in Release 1 — Rolle wird nur behauptet, nicht geprüft. |T-001, T-002 (Kapitel 8.1), PRD "Authentifizierung"
|R-02 |Optimistisches Locking (ADR-0006) setzt korrekte Versionsprüfung in jedem Repository voraus — ein vergessenes `WHERE version = ?` unterläuft BR-NL-01/02 stillschweigend. |ADR-0006, T-004
|R-03 |Kein Migrationswerkzeug (ADR-0004) — Schema-änderungen sind manuelle Handarbeit, Risiko wachsender Divergenz zwischen `schema.sql` und Code. |ADR-0004
|R-04 |Reservierungsverfall (BR-VM-04) hängt an einer austauschbaren Zeitquelle — falsch konfiguriert, verfallen Reservierungen zur falschen Zeit. |BR-VM-04
|R-05 |SQLite-Datei liegt ungeschützt im Dateisystem — kein Verschlüsselung-at-rest vorgesehen. |T-005 (Kapitel 8.1)
|R-06 |Kein Rate-Limiting auf der REST-API. |T-006 (Kapitel 8.1)
|===
