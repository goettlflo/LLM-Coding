== Glossar

Gilt unverändert für Spezifikation, Architektur und Code (`src/docs/specs/prd.adoc`, Abschnitt "Glossar").

[cols="e,2e" options="header"]
|===
|Begriff |Definition

|Gegenstand |Ein einzelnes physisches Exemplar mit eigener Inventarnummer.
|Kategorie |Gruppe gleichartiger Gegenstände. Bestimmt Leihdauer, Wartungsintervall und Einweisungspflicht.
|Mitglied |Person, die ausleihen darf.
|Thekendienst |Rolle, die Gegenstände ausgibt und zurücknimmt.
|Wart |Rolle, die prüft, wartet, ausmustert und über Kautionsabzüge entscheidet.
|Ausleihe |Vorgang von der Ausgabe bis zum Abschluss der Prüfung.
|Rückgabe |Übergabe des Gegenstands an die Theke. Beendet die Ausleihe nicht.
|Prüfung |Kontrolle des Gegenstands nach der Rückgabe.
|Prüfprotokoll |Ergebnis einer Prüfung. Schließt die Ausleihe ab.
|Kaution |Bei der Ausgabe hinterlegter Betrag. Keine Gebühr.
|Öffnungstag |Dienstag oder Samstag. Einziger Tag, an dem die Theke besetzt ist.
|BR-ID |Eindeutiger Bezeichner einer Geschäftsregel, siehe `geschaeftsregeln.adoc`.
|UC-ID |Eindeutiger Bezeichner eines Persona Use Case, siehe `use-cases.adoc`.
|SUC-ID |Eindeutiger Bezeichner eines System Use Case (REST/CLI), siehe `system-use-cases.adoc`.
|ADR |Architecture Decision Record, Nygard-Format mit Pugh-Matrix, siehe `src/docs/arc42/adr/`.
|===
