[[section-architecture-constraints]]
== Randbedingungen

[cols="1,3" options="header"]
|===
|Art |Randbedingung

|Technisch |REST-API für alle Anwendungsfälle, zusätzlich CLI für den Wart, keine Web-Oberfläche (PRD "Rahmenbedingungen").
|Technisch |Ein Prozess, lokal startbar, ohne externe Dienste — kein Mailversand, keine Zahlungsanbindung, keine Cloud.
|Technisch |Aktuelles Datum über austauschbare Quelle, damit Fristen (BR-VM-04, BR-SP-02) testbar bleiben.
|Organisatorisch |Rollen kommen über Header/CLI-Flag, keine echte Authentifizierung in Release 1 (siehe Risiko R-01, Kapitel 11).
|Sprachlich |Fachbegriffe im Code folgen dem Glossar aus `prd.adoc` (Kapitel 12 verweist darauf).
|Technologie |Sprache, Framework, Persistenz frei wählbar → festgelegt in ADR-0001 bis ADR-0006 (`src/docs/arc42/adr/`).
|===
