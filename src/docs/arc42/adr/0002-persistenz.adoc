= ADR-0002: Persistenz
Status: Akzeptiert

== Kontext

PRD, Abschnitt "Rahmenbedingungen": Ein Prozess, lokal startbar, ohne externe Dienste.
Umfang: rund 400 Gegenstände, 800 Mitglieder — kleine Datenmenge.
Qualitätsziel "Antwortzeit": unter 300 ms (95. Perzentil) bei dieser Last.
BR-NL-01/02 verlangen atomare Schreiboperationen bei gleichzeitigem Zugriff.

== Entscheidung

SQLite als eingebettete Datei-Datenbank. Die Datenbankdatei liegt lokal neben dem Prozess, kein separater Serverprozess nötig.

== Konsequenzen

* DB-Zugriff wird separat entschieden (ADR-0004).
* Migrationen (Schema-Aufbau) müssen versioniert werden, auch ohne ORM — eigenes Schema-Skript unter Versionskontrolle.
* Backups sind eine Datei-Kopie; kein Betriebsthema für dieses Release (siehe PRD "Nicht-Ziele").
