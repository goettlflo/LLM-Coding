== Beschreibung

Ein Mitglied wird gesperrt, sobald eine Ausleihe überfällig ist, und bleibt gesperrt, bis alle überfälligen Ausleihen geprüft sind — nicht schon mit der Rückgabe.

== Akzeptanzkriterien

[source,gherkin]
----
Given eine Ausleihe mit Rückgabefrist vor dem heutigen Datum, nicht zurückgegeben
When der heutige Tag beginnt
Then gilt das Mitglied als gesperrt
----
