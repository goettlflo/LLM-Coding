Lesender Zugriff für Mitglieder, um vor dem Theken-Besuch Status und Warteschlangenposition zu prüfen (Persona Sabine). Kein Kontrollfluss-kritisches Feature, daher Should statt Must.

Then wird der aktuelle Zustand ohne Seiteneffekt zurückgegeben
