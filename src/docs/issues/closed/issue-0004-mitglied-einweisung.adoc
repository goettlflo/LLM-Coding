== Beschreibung

Mitglieder anlegen und dokumentierte Einweisungen für eine Kategorie erfassen — Grundlage für die Ausgabeprüfung einweisungspflichtiger Gegenstände (BR-AUS-04) in Issue 0007.

== Akzeptanzkriterien

[source,gherkin]
----
Given ein Mitglied ohne Einweisung
When eine Einweisung für eine Kategorie erfasst wird
Then gilt das Mitglied für diese Kategorie als eingewiesen
And für andere Kategorien weiterhin nicht
----
