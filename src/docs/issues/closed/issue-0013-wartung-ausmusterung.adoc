== Beschreibung

Der Wart schließt eine erledigte Wartung ab oder mustert einen Gegenstand endgültig aus.

== Akzeptanzkriterien

[source,gherkin]
----
Given ein wartungsfälliger Gegenstand
When der Wart die Wartung abschließt
Then wird der Gegenstand verfügbar und der Nutzungszähler auf null gesetzt
----
