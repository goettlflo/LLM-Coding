== Beschreibung

Mitglieder merken Kategorien vor; wird ein Gegenstand dieser Kategorie verfügbar, geht er automatisch und atomar an das erste Warteschlangenmitglied — mit Verfall der Reservierung nach Öffnungstagen. Kernanliegen von Sabine (Mitglied, PRD Persona).

== Akzeptanzkriterien

[source,gherkin]
----
Given eine Vormerkung für eine Kategorie ohne verfügbaren Gegenstand
When ein Gegenstand dieser Kategorie nach der Prüfung verfügbar wird
Then wird er für das erste Mitglied der Warteschlange reserviert
----
