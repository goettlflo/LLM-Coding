== Beschreibung

Ausgabe eines Gegenstands an der Theke und dessen Verlängerung — der Kernprozess, den Karim (Thekendienst) in Sekunden abwickeln will (PRD Persona).

== Akzeptanzkriterien

[source,gherkin]
----
Given ein verfügbarer, nicht einweisungspflichtiger Gegenstand und ein unbeschränktes Mitglied
When das Mitglied den Gegenstand ausleiht
Then wird die Ausleihe angelegt, die Kaution hinterlegt und die Rückgabefrist gesetzt
----
