== Beschreibung

VormerkungService.vormerken(): reiht eine Vormerkung nach Eingangszeit in die Warteschlange der Kategorie ein — unabhängig von einer bestehenden Sperre des Mitglieds.

== Akzeptanzkriterien

[source,gherkin]
----
# BR-VM-01 / BR-VM-02
Szenario: Vormerkung reiht sich nach Eingangszeit ein
  Angenommen eine Kategorie hat bereits eine Vormerkung
  Wenn ein weiteres Mitglied dieselbe Kategorie vormerkt
  Dann steht es an zweiter Stelle der Warteschlange

# BR-VM-08
Szenario: Gesperrtes Mitglied darf vormerken
  Angenommen ein Mitglied ist gesperrt
  Wenn es eine Kategorie vormerkt
  Dann wird die Vormerkung angenommen
----

== Abhängigkeiten

- 0003 (Gegenstand/Kategorie anlegen und abfragen)
